# 주문 002 — 마이노트 비서 1단계: 먼저 빌드, 폰은 마지막

이미 끝난 것(001): GitHub 자료 복사, AGENTS.md 정본·설치 규칙·주문 절차 반영. 다시 하지 않는다.

## A. 폰 없이 끝까지 (폰 연결과 무관)
1. `90_작업기록\비서_1단계\stage1\코덱스_지시서_1단계.md` 의 1~3번 적용 (code20 정본 위, versionCode 21 / versionName 0.6.0).
2. `gradlew testDebugUnitTest assembleDebug`. 실패하면 **여기서 중단**, 실패 테스트·오류 전문 보고.
3. 마이그레이션 검사: 이전 버전 DB 에 합성 카드 3건 → 새 버전으로 열어 3건·내용 동일. 실패하면 **중단**.
4. APK 를 `_apk\마이노트_0.6.0_code21.apk` 로 보관하고 SHA256 기록.

## B. 설치 (폰 필요)
5. `adb devices -l` 에 SM-F966N 이 없으면 형에게 "폰 설정 → 개발자 옵션 → 무선 디버깅 화면의 IP:포트" 를 물어 `adb connect IP:포트`.
   그래도 안 되면 **"빌드 완료·미설치"** 로 보고하고 멈춘다(이 주문은 완료 원장에 넣지 않는다 → 다음 "주문 확인" 때 5번부터 재개).
6. `powershell -ExecutionPolicy Bypass -File tools\install_gate.ps1`. 실패 시 자동 롤백 상태 그대로 두고 로그 경로 보고.
7. 통과하면 형에게 폰 확인 2가지 요청:
   - 비서 입력칸 "다음주 화요일 오후 2시 현장검증" → 제안 → [등록] → 폰 캘린더에 보임
   - 음성메모 1건 → 전사됨
8. 기록: `90_작업기록\작업지침_20261022_마이노트_비서1단계.md` 에 이어 쓴다. 테스트·빌드·설치·폰 확인을 구분. 확인 안 한 건 "미검증".
9. 7번까지 끝났을 때만 `_orders_done.txt` 에 이 파일명을 추가한다.

## 금지
- `adb install` 직접 실행, 앱 삭제, 데이터 초기화.
- 기존 Room 테이블·카드·리포트·전사 데이터 형식 변경.
- 형 승인 없이 캘린더에 쓰는 코드 경로.
- 통화·녹음·개인 파일 외부 전송.
