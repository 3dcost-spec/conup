# 주문 001 — 마이노트 비서 1단계 빌드·폰 설치

## 전제
- 형이 폰 무선 디버깅을 연결했다고 했다.
- 정본 = `작업지침_20261020_마이노트_세컨브레인B1_code20.md` 에 적힌 code20 소스 폴더. AGENTS.md 에 "정본 = <경로>" 가 없으면 적는다.
- 1단계 자료: 이 저장소 `mynote-assistant/stage1/`, 설치 관문: `mynote-assistant/release-gate/`.

## 단계
1. `adb devices -l` → SM-F966N 이 `device` 인지 확인. 아니면 **중단**, 사유 보고.
2. 자료 복사
   - `mynote-assistant/stage1` → `16_마이노트\90_작업기록\비서_1단계\stage1`
   - `mynote-assistant/release-gate/install_gate.ps1` → 정본 `tools\install_gate.ps1` (이미 있으면 내용 비교 후 다를 때만 교체)
3. `stage1\코덱스_지시서_1단계.md` 의 1~3번 적용 (파일 6개, 가산형 마이그레이션, 리포트→제안·비서 카드·주 캘린더 설정).
   - code20 위에 얹는다. versionCode 21, versionName 0.6.0.
4. `gradlew testDebugUnitTest assembleDebug` — 실패하면 **설치하지 말고 중단**, 실패 테스트·오류 전문 보고.
5. 마이그레이션 검사: 이전 버전 DB 에 합성 카드 3건 → 새 버전으로 열기 → 3건·내용 동일. 실패하면 **중단**.
6. `powershell -ExecutionPolicy Bypass -File tools\install_gate.ps1` 로 설치. 실패 시 자동 롤백 상태 그대로 두고 로그 경로 보고.
7. 통과하면 형에게 폰 확인 2가지 요청:
   - 비서 입력칸 "다음주 화요일 오후 2시 현장검증" → 제안 → [등록] → 폰 캘린더에 보임
   - 음성메모 1건 → 전사됨 (10/19 전사 복구 회귀 확인)
8. 기록: `90_작업기록\작업지침_20261022_마이노트_비서1단계.md` — 바뀐 파일, 테스트 결과, 빌드, 설치, 폰 확인을 각각 구분. 확인 안 한 건 "미검증".

## 금지
- `adb install` 직접 실행, 앱 삭제, 데이터 초기화.
- 기존 Room 테이블·카드·리포트·전사 데이터 형식 변경.
- 형 승인 없이 캘린더에 쓰는 코드 경로.
- 통화·녹음·개인 파일 외부 전송.
