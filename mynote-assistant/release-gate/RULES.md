# 마이노트 깨짐 방지 규칙 (AGENTS.md 에 그대로 추가)

## 폰 설치
1. 폰 설치는 **오직 `tools\install_gate.ps1`** 로 한다. `adb install` 직접 실행 금지.
2. versionName 에 dev·test·alpha 가 들어간 빌드는 운영폰 설치 금지. 개발본은 에뮬레이터나 별도 폰에서만.
3. 설치 전 현재 APK를 `_apk\_stable\rollback_*.apk` 로 백업하고, 실행 후 크래시·권한 차단·파싱 오류가 보이면 자동으로 되돌린다.
4. 앱 삭제·데이터 초기화·uninstall 금지.

## 코드 수정
5. 한 번에 한 기능만 고친다. 전사·통화·리포트·권한을 한 커밋에 섞지 않는다.
6. **전사 계약은 고정이다**: Gemini 응답의 transcript 항목은 startMs·endMs·speaker·text 를 계속 받는다. 화면·복사·내보내기에서 숨기는 것은 표시 단계에서만 한다. 데이터 형식을 바꾸지 않는다.
7. 전사·통화·리포트를 건드리는 수정은 아래 회귀 테스트를 반드시 추가·통과시킨다.
   - 저장된 Gemini 응답 샘플(합성) 3종을 AiResult 로 파싱 → 성공
   - 시간 없는 화면 표시 문자열 생성 → 시간 패턴 0건
   - ProcessCardWorker 가 기기 개인 저장소(device-personal)에서 차단되지 않음
8. 권한·보안 게이트를 새로 넣을 때 기본값은 "기존 개인 기록은 그대로 동작"이다. 기본 차단으로 기존 기능을 끄지 않는다.
