# 코덱스 지시서 — 마이노트 비서 1단계: 일정 제안·캘린더 등록

## 0. 시작 전 (안 하면 착수 금지)
1. **정본 확정**: 폰에 설치된 0.5.0/code19 의 소스 폴더를 먼저 찾는다(전사복구 작업에서 미확인). 못 찾으면 멈추고 보고한다. 다른 버전 소스로 작업하지 않는다.
2. 그 폴더 AGENTS.md 에 "정본 = <경로>" 한 줄을 적는다.
3. `tools\install_gate.ps1` 이 없으면 GitHub 3dcost-spec/conup 브랜치 claude/mynote-ai-assistant-planning-llpb71 의 `mynote-assistant/release-gate/` 에서 가져와 넣는다.

## 1. 파일 넣기 (패키지 com.cmx.mynote.assistant)
`stage1/android/assistant/` 의 6개 파일을 `app/src/main/java/com/cmx/mynote/assistant/` 로:
- `KrDateTimeParser.java` — 한국어 날짜 해석 (순수 자바, 이 세션에서 테스트 27개 통과)
- `ReportScheduleExtractor.java` — 일일 리포트 ① 절에서 [확정] 일정만 제안 후보로
- `CalendarEvent.kt` — 일정 테이블 + DAO + 마이그레이션 SQL
- `CalendarWriter.kt` — 폰 캘린더(네이버 DAVx⁵·구글) 쓰기, UID 로 중복 방지
- `AssistantScheduler.kt` — 제안·승인·거절 흐름
`stage1/test/ParserTest.java` 는 `app/src/test/java/` 로 옮겨 JUnit 으로 감싼다(main 의 check 들을 @Test 로).

## 2. DB 연결 (가산형만)
- AppDatabase: entities 에 CalendarEvent 추가, `abstract fun calendarEventDao(): CalendarEventDao`, version N → N+1.
- `Migration(N, N+1)`: `CREATE_CALENDAR_EVENTS_SQL` 실행 후 `CALENDAR_INDEX_SQL` 각각 실행. 기존 테이블 SQL 변경 금지.
- `fallbackToDestructiveMigration` 이 있으면 절대 쓰이지 않게 확인(있으면 보고).

## 3. 흐름 연결
- **리포트 → 제안**: ReportWorker 가 일일 리포트를 저장한 직후 `AssistantScheduler.proposeFromReport(markdown, "daily:<날짜>", 리포트날짜 기준 now, [자료N]→cardId 맵)`. 실패해도 리포트 저장은 성공으로 둔다(try/catch, 로그만).
- **비서 화면**: 오늘 화면 상단에 "일정 제안 N건" 카드. 펼치면 제안마다 [등록] [거절]. [등록] → 설정의 주 캘린더 ID 로 `confirmAndWrite`. 결과 문구를 그대로 토스트.
- **자연어 입력**: 비서 카드에 입력칸 1개. 입력 → `proposeFromText` → 돌아온 문구 표시.
- **설정**: "비서 · 캘린더" 에 주 캘린더 선택(0단계 CalendarProviderProbe.listCalendars 재사용, 네이버(DAVx⁵) 기본 추천). 선택값은 SettingsStore 에 저장.
- 0단계 실측 버튼은 그대로 둔다.

## 4. 금지
- 비서가 승인 없이 캘린더에 쓰지 않는다. 제안 → 형이 [등록] 눌러야만 쓴다.
- 일정 내용·통화 원문을 외부로 보내지 않는다(이 단계는 AI 호출 없음).
- 기존 Room 테이블·카드·리포트 형식 변경 금지. 전사 데이터 형식 변경 금지.

## 5. 검증·설치
1. `gradlew testDebugUnitTest` — ParserTest 27개 포함 전부 통과
2. 마이그레이션 테스트: N 버전 DB 에 합성 카드 3건 넣고 N+1 로 열어 카드 3건·내용 동일 확인
3. versionCode 20 이상, versionName 0.6.0 (dev 금지)
4. 설치는 `tools\install_gate.ps1` 로만
5. 폰 확인: 비서 입력칸에 "다음주 화요일 오후 2시 현장검증" → 제안 → [등록] → 폰 캘린더·네이버 캘린더(DAVx⁵ 동기화 후)에 보이는지
6. `90_작업기록\작업지침_<날짜>_마이노트_비서1단계.md` 에 기록. "빌드 성공"과 "폰 확인"을 구분해서 쓴다.
