작업 전 `16_마이노트\AGENTS.md`와 `docs\마이노트_AI브레인_개발계약_20261013.md` 를 읽는다. 기존 Room 스키마·카드 데이터는 건드리지 않는다.

## 1. 파일 넣기
- `android\CalendarProviderProbe.kt` → `app\src\main\java\com\cmx\mynote\calendar\CalendarProviderProbe.kt` (새 패키지)

## 2. AndroidManifest.xml 권한 2줄 추가
```xml
<uses-permission android:name="android.permission.READ_CALENDAR"/>
<uses-permission android:name="android.permission.WRITE_CALENDAR"/>
```

## 3. 설정 화면에 "비서 · 캘린더 실측" 섹션 추가 (`ui/settings/SettingsScreen.kt`)
- 버튼 1: 「캘린더 권한 요청」 → READ/WRITE_CALENDAR 런타임 요청
- 버튼 2: 「캘린더 목록」 → `CalendarProviderProbe(context).listCalendars()` 결과를 `이름 · 계정 · accountType · 쓰기가능` 으로 나열. `accountType=bitfire.at.davdroid` 행은 "네이버(DAVx⁵)" 라벨
- 버튼 3: 「왕복 테스트(삭제 안 함)」 → 선택한 캘린더로 `roundTrip(id, keep=true)` → 단계별 ok/실패를 화면에 표시하고, JSON으로 직렬화해 기존 `MarkdownWriter`/`DropboxClient` 업로드 경로 옆에 `.sync/assistant/probe/android_<yyyyMMdd_HHmm>.json` 저장
- 사용자 실제 일정 본문은 읽지 않는다. `countUpcoming` 은 건수만.

## 4. 빌드·설치
```powershell
cd "H:\공유 드라이브\CMX_워크센터\00_AI파이선\16_마이노트"
.\gradlew.bat assembleDebug --console=plain
adb devices            # 무선 디버깅 연결 확인, 끊겼으면 재페어링
adb install -r app\build\outputs\apk\debug\app-debug.apk
```
APK 복사본은 `_apk\마이노트_통합_0.5.0_캘린더실측.apk` 로 보관.

## 5. 설치 후 확인 (폰)
1. DAVx⁵ 설치·네이버 계정 추가·동기화 1회 (README §2)
2. 마이노트 설정 → 비서 → 캘린더 권한 요청 → 캘린더 목록에 네이버(DAVx⁵) 행이 보이는지
3. 왕복 테스트 → 전 단계 ok
4. DAVx⁵ 수동 동기화 → 네이버 캘린더 웹에서 "[마이노트 실측]" 일정 확인
