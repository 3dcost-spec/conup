출처: `특정건축물정리법_시행령안_입법예고_2026.hwpx` (국토교통부 건축정책과). 아키엠 매핑 열은 기획안 §7 데이터 모델 기준.

## 별지 제1호서식 — 특정건축물 신고서 (3쪽)

### 1쪽
| 구역 | 항목 | 입력 형식 | 아키엠 데이터 |
|---|---|---|---|
| 접수(음영) | 신고번호 / 접수일자 / 처리일자 / 처리기간 30일 | 기관 기재 | Filing.receipt_no 등(수령 후 입력) |
| 위반구분 | 신축 / 증축 / 개축 / 재축 / 이전 / 대수선 / 용도변경 / 기타( ) | 복수 체크 | Violation.type_code 집계 |
| 허가·신고 여부 | 해당 / 미해당 | 체크 | BuildingRecord.permit_exists (법 제2조1항1호 가목/나목 판별) |
| 신고인(소유자) | 성명(법인명), 생년월일(사업자·법인등록번호), 주소, 전화번호 | 텍스트 | Applicant |
| 현장조사자(건축사) | 성명(서명/인), 자격번호, 사무소명, 신고번호, 사무소주소, 전화번호 | 텍스트+서명 | 건축사 프로필(등록번호·사무소 신고번호 필드 추가) |
| 용도 | 주용도 / 부속용도 / 착공일 / 완공일 | 텍스트·날짜 | BuildingRecord.use, Eligibility.completion |
| 대지현황 | 위치, 면적(㎡), 지목, 전면도로폭(m), 지역, 도로에 접하는 대지의 길이, 지구/구역, 소유구분[자가소유 / 타인소유: 사용승락(집합건물법 결의 포함) / 국·공유지] | 텍스트·체크 | Site (+ road_width, frontage_length, ownership_type) |
| 건축물 현황 | 행: **허가(신고) 당시** / **현재(신청일)** × 열: 건축면적(㎡), 연면적(㎡), 용적률(%), 건폐율(%), 주용도, 세대/호, 주차대수 | 2행 7열 | BuildingRecord(대장) vs Calculation(실측) — 위반현황표와 동일 데이터 |
| 서명 | 년월일, 신고인(서명/인), **현장조사자(서명/인)**, 수신: 특별자치시장·특별자치도지사, 시장·군수·구청장 | 서명 | 서명 칸은 비움(태그) |

### 2쪽 — 특정건축물의 동별 개요(동마다 작성)
| 구역 | 항목 | 아키엠 데이터 |
|---|---|---|
| 동명칭 | 주건축물 제1동 … | Project 동 구조 |
| 층수 | 지상 n층 / 지하 n층 | BuildingRecord.floors |
| 구조 | 지붕 / 벽체 / 바닥 ; 최고높이 / 처마높이 / 반자높이 | BuildingRecord.structure + Measurement(높이 3종 신규) |
| 층별 표(8행) | 층 / ①기존건축물 바닥면적 / 위반현황[③허가·신고, ④허가·신고 외] / ⑤위반유형 / ⑥위반시점 / ⑦세대수(가구·호) / ②이행강제금[부과횟수, 부과금액, 납부금액] | Violation(층별) + PenaltyEstimate(기납부 내역) |
| 다세대 호/세대별 면적 | 기존 건축물 개요 vs 신고 건축물 개요: 공용공간 전체 면적(㎡), 호(세대) 구분 / 층 / 전용면적(㎡) | Unit 테이블(신규) — 세대당 85㎡ 판정 근거 |
| 이격 위반 | 건축선: m, ㎡ / 인접대지경계선: m, ㎡ | Violation(type=V11/V12) + Measurement |

작성방법 요지: ①적법부분 면적(위반 제외), ②이행강제금 부과·납부 내역, ③해당 층의 허가·신고 면적(기존 제외), ④무허가는 전체·일부 허가 시 위반부분 면적, ⑤위반유형(증축·개축·대수선·용도변경 등), ⑥사실상 완공(용도변경은 주택 사용 개시) 연도, ⑦완공 시점 세대수. 용도는 「건축법 시행령」 별표 1 구분.

|---|---|

| 처리절차 | 신고서 작성 → 접수 → 대상건축물 여부 판단 → 건축위원회 심의 → 사용승인서 작성 → 발급 (영 제6조3항 자료 요청 가능) |

## 별지 제2호서식 — 특정건축물 현장조사서 (3쪽)

### 1쪽
| 구역 | 항목 | 입력 형식 | 아키엠 조사 분야 / 데이터 |
|---|---|---|---|
| ①국가시책 | 사업명(허가번호), 허가일(지시일) | 텍스트 | Eligibility.national_project(신규 축) |
| 신고인(소유자) | 성명(법인명), 생년월일(등록번호) | 텍스트 | Applicant |
| 건축물 개요 | 위치, 용도, 구조 | 텍스트 | BuildingRecord |
| 조사사항 — 대지 현황 | 대지의 안전 / 도로와의 관계 / **3미터 이상 도로에 접하는 길이** / 상수도시설 현황 / 하수도시설 현황 | 서술 | 대지·설비 체크리스트, Site.frontage_length |
| 조사사항 — ②건축물 현황 | 구조안전 / 소방상 지장 유무 / 위생상 지장 유무 / 피난상 지장 유무 / 도시계획상 지장 유무 | 지장 유무 + 간략 내용 | 구조·피난방화·설비 체크리스트, 토지이용계획 플래그 |
| 조사사항 — 주차장 현황 | 추가 설치 의무 비대상[법 제7조1항(단서 외) □, 2항 □] / 추가 설치 검토 대상[추가 필요 주차구획 수 ( )개소, 면제 □] / 확보방법[설치 □, 비용납부 □, 해당없음 □] | 체크+수치 | 대지 체크리스트 + 주차 산정(신규 로직: 법 제7조) |
| 위반사항 | 면적 및 층수 위반 / 건축선 침범 / 건축선으로부터 띄어야 할 거리 위반 / 인접대지경계선으로부터 띄어야 할 거리 위반 / 대수선 위반 / 용도변경 위반 / 그 밖의 위반사항 — 각 해당 □ / 해당없음 □ | 7항목 체크 | Violation.type_code 집계 → 자동 체크 |
| 종합의견 | 서술 | 서술 | AI 초안 → 건축사 확정 |
| 증명·서명 | "위의 사항에 관하여 틀림없이 조사하였음을 증명합니다." 년월일, **현장조사자(서명/인)** | 서명 | 서명 칸 비움 |

작성방법: ①란은 국가시책사업(생활환경정비·재해복구)인 경우만, 이 경우 지자체 작성 조사서로 갈음 가능. ②란은 항목별 지장 유무와 지장 내용을 간략히.

### 2쪽 — 특정건축물의 동별 세부현황(층 열 5개)
| 구역 | 행 항목 | 아키엠 데이터 |
|---|---|---|
| 동명칭 | 적법부분 바닥면적(㎡) | Violation.area_record(적법) |
| 허가·신고하지 않고 위반한 건축물 | 위반유형 **건축**: 바닥면적 / 위반 시점 / 위반 내용 ; **대수선**: 위반 시점 / 위반 내용 ; **용도변경**: 바닥면적 / 위반 시점 / 위반 내용 ; **그 밖의 위반**: 바닥면적 / 위반 시점 / 위반 내용 ; 합계 | Violation(permit=false) 층별 |
| 허가·신고하였으나 사용승인을 받지 못한 건축물 | 허가·신고한 부분 바닥면적 ; 위반 현황 **②허가·신고 부분**(바닥면적·시점·내용: 위치변경 등으로 공지·일조 위반) ; **③허가·신고 외의 부분**(바닥면적·시점·내용) ; 그 밖의 위반 ; 합계 | Violation(permit=true) 층별 |
| 합계 | 층별 합계 | Calculation |
| 용도 및 용도별 면적 | 용도 열 5 + 합계 | Calculation.use_areas |
| 층수 | 지상 n층 / 지하 n층 | BuildingRecord |
| 구조 | 지붕 / 벽체 / 바닥 ; 최고높이 / 처마높이 / 반자높이 | 신고서 2쪽과 동일 |
| 이격 위반 | 건축선 m, ㎡ / 인접대지경계선 m, ㎡ | 신고서 2쪽과 동일 |

## 신고서·현장조사서 교차 일치 항목(자동 동기화 필수)
- 동별 층수·구조(지붕·벽체·바닥)·높이 3종(최고·처마·반자)
- 건축선·인접대지경계선 이격 위반(m, ㎡)
- 층별 위반 바닥면적·위반유형·위반시점 (신고서 2쇽 ③④⑤⑥ ↔ 조사서 2쪽 세부현황)
- 건축물 현황(허가 당시 vs 현재) ↔ 용도별 면적 합계

## 아키엠 위반유형 코드 재편(제정안 기준)
| 코드 | 제정안 명칭 | 비고 |
|---|---|---|
| V-A 건축 | 허가·신고 없이 건축(신축·증축·개축·재축·이전) | 신고서 위반구분 체크와 연결 |
| V-B 대수선 | 대수선 위반 | 바닥면적 없음, 시점·내용만 |
| V-C 용도변경 | 용도변경 위반 | 주택용도 사용 개시 연도 = 위반시점 |
| V-D 면적·층수 | 면적 및 층수 위반 | 허가·신고 후 초과 |
| V-E 건축선 침범 | 건축선 침범 | m, ㎡ |
| V-F 건축선 이격 | 건축선으로부터 띄어야 할 거리 위반 | m, ㎡ |
| V-G 인접대지 이격 | 인접대지경계선으로부터 띄어야 할 거리 위반 | m, ㎡ |
| V-H 공지·일조(허가부분) | 허가·신고 부분의 위치변경 등으로 대지 안의 공지·일조 위반(조사서 ②) | 조사서 2쪽 전용 |
| V-Z 그 밖의 위반 | 그 밖의 위반사항 | 자유 기재 |

세부 관찰 라벨(옥탑·발코니 확장·필로티 전용·세대분할·다락 거실화 등)은 **AI 제안용 하위 태그**로 두고, 서식에는 위 코드로 집계해 기재한다.
