# 조사 메모 — 건축면적·바닥면적 산정(옥탑·발코니) 및 주차장 특례(법 제7조)

## 1. 건축법 시행령 제119조 — 양성화 산정에 쓰는 규칙

### 1-1. 건축면적(제1항 제2호)
- 원칙: **외벽(없으면 외곽 기둥) 중심선으로 둘러싸인 부분의 수평투영면적**.
- 처마·차양·부연 등이 외벽 중심선에서 **1m 이상 돌출**하면 돌출 끝에서 일정 거리(일반 1m, 한옥 2m, 사료투여 축사 3m, 전통사찰 4m 등) 후퇴한 선으로 산정.
- 산입 제외: **지표면으로부터 1m 이하 부분**(창고 차량 접안부 1.5m), 장애인용 승강기·경사로·리프트, 영유아 대피시설 등.
- 외부계단은 건축면적에 **모두 산입**(법제처 해석).

### 1-2. 바닥면적(제1항 제3호)
- 원칙: 각 층 벽·기둥 등 구획의 중심선으로 둘러싸인 수평투영면적. 구획 없으면 지붕 끝에서 1m 후퇴.
- **노대(발코니)**: 노대 면적 − (노대가 접한 가장 긴 외벽 길이 × 1.5m) 를 바닥면적에 산입(제3호 나목, 구판 다목).
- 산입 제외: 필로티(통행·주차·공동주택), **승강기탑·계단탑·장식탑·다락(층고 1.5m, 경사지붕 1.8m 이하)·물탱크·굴뚝 등**, 공동주택 지상층 기계실·어린이놀이터·조경시설 등.
- 법제처 해석: 바닥면적 제외되는 "계단탑"은 계단 용도 공간에 한정. **거실로 쓰는 옥탑방은 계단탑이 아니므로 바닥면적·연면적에 산입**된다.

### 1-3. 층수·높이(제1항 제5호·제9호)
- 옥상의 승강기탑·계단탑·망루·장식탑·**옥탑** 등 수평투영면적 합계가 **건축면적의 1/8 이하**(85㎡ 이하 사업승인 공동주택 1/6)이면 **층수에서 제외**, 높이는 12m 초과 부분만 산입.
- 수평투영면적은 외벽 중심선 기준으로 재며, 건축면적의 예외(처마 후퇴 등)는 층수 산정에 적용하지 않는다(법제처 해석, 장애인용 승강기탑 사례).
- 지하층은 층수 제외.

### 1-4. 양성화 산정 규칙(아키엠 적용안 — 건축사 최종 확인 전제)

| 위반 유형 | 건축면적 | 바닥면적·연면적 | 층수 | 비고 |
|---|---|---|---|---|
| **옥탑 증축(거실 용도)** | 하부층 외벽선 안이면 **증가 0**, 외벽선 밖으로 돌출하면 돌출분 가산 | **전부 산입**(계단탑 예외 아님) | 수평투영 ≤ 건축면적 1/8이면 층수 불변, 초과하면 **+1층** | 1/8 판정은 기존 승강기탑·계단탑 면적을 합산 |
| **발코니 확장(외벽 밖 돌출 증축)** | 외벽 중심선 이동분 **가산** | 노대로 남아 있으면 (면적 − 긴 변×1.5m) 산입, **창호·벽으로 막아 거실화했으면 전부 산입** | 불변 | 거실화 여부를 사진·체크로 판정 |
| 기존 노대를 실내화(돌출 없음) | 증가 0 | 공제분(긴 변×1.5m)이 **산입으로 전환** → 연면적 증가 | 불변 | 대수선·용도변경 성격 병존 가능 |
| 필로티 주차장 → 거실 전용 | 증가 0 | 제외분 **전부 산입** | 필로티 층이 층수에 **추가**될 수 있음(주차장 외 용도) | 주차대수 감소 → 법 제7조 검토 |
| 지하 거실화 | 증가 0(지표 1m 이하) | 산입(용적률 산정 연면적에서는 지하층 제외) | 지하층 층수 제외 | 용도변경 |
| 외부계단·캐노피·창고 증축 | **가산** | 창고·거실은 산입, 캐노피는 지붕 끝 1m 후퇴 | 불변 | |
| 세대 분할(방 쪼개기) | 증가 0 | 증가 0 | 불변 | 세대수·주차·전용면적만 변동 |
| 다락(층고 1.5m 초과) | 증가 0 | 1.5m(경사 1.8m) 초과 시 **산입** | 통상 불변 | 층고 실측 필수 |

- 신고서 1쪽 「건축물 현황 — 현재(신청일)」의 건축면적·연면적·건폐율·용적률은 위 규칙으로 계산한다. 용적률용 연면적은 지하층·지상 주차장(필로티)·주민공동시설 등 제외 규정(제4호)을 따른다.
- 이행강제금 위반면적은 지자체가 **바닥면적 기준**으로 부과하는 것이 일반적이나 조례·실무 차이가 있어, 아키엠은 바닥면적을 기본값으로 두고 지자체 파라미터로 조정한다.

## 2. 법 제7조 — 부설주차장 특례(현장조사서 「주차장 현황」 칸의 근거)

검색으로 확인된 조문 취지(법률 제21820호, 발의안·대안·해설 교차):

| 항 | 내용 | 현장조사서 칸 |
|---|---|---|
| 제1항 본문 | 법 제6조 사용승인으로 「주차장법」 제19조 부설주차장 설치기준에 **미달**하게 된 대상건축물의 건축주·소유자는 **추가 설치 의무를 지지 않는다** | 「추가 설치 의무 비대상 — 법 제7조 제1항(단서 외 부분) □」 |
| 제1항 단서 | **세대·가구·호수를 증가**시키는 대수선 또는 **근린생활시설 등 → 주택 용도변경**인 경우는 추가 설치 의무 유지(설치 또는 **설치비용 납부**) | 「추가 설치 검토 대상 — 추가 필요 주차구획 수 ( )개소」 + 「확보방법: 설치 □ / 비용납부 □」 |
| 제2항 | **전세사기피해주택**(전세사기피해자가 매수)은 추가 설치 의무 면제 | 「법 제7조 제2항 □」 |
| 조례 위임 | 지자체 조례로 설치기준 완화·면제 가능 | 「면제 □」 |

유의: 이 특례는 건축법·주차장법 설치의무에 대한 것이며 타법 위반을 자동 면제하지 않는다는 해설이 있다. 비용납부 금액은 지자체 부설주차장 설치 조례 단가.

### 2-1. 아키엠 주차 판정 로직(Parking)

```
입력: units_before(허가 당시 세대수), units_after(현재), use_change_to_house(근생 등→주택 용도변경 여부),
      parking_before(허가 당시 대수), parking_now(현재 실측 대수), required_now(주차장법·조례 기준 산정),
      is_jeonse_fraud_victim_house(bool), ordinance_exempt(bool)

if is_jeonse_fraud_victim_house: → 비대상(제2항)
elif units_after <= units_before and not use_change_to_house: → 비대상(제1항 본문)   # 면적 증가만으로는 추가 의무 없음
else: → 검토 대상(제1항 단서)
      needed = max(0, required_now − parking_now)
      if ordinance_exempt: 면제 □
      else: 확보방법 = 설치 | 비용납부(조례 단가 × needed) 중 사용자 선택
```
- required_now 산정은 「주차장법 시행령」 별표1 + 지자체 조례(JurisdictionParams.parking_rule)로 계산, MVP는 수동 입력 허용.
- 필로티 주차장 전용(V-A tag 필로티전용)이 있으면 parking_now 감소를 자동 반영하고 검토 대상 경고.

## 3. 미확인·후속
- 법 제7조 공포본 문언(단서의 정확한 범위, "설치비용 납부" 근거가 법인지 조례인지) → 국가법령정보센터 원문 대조.
- 건축법 시행령 제119조 현행(2025.1.21 시행, 대통령령 제35221호) 제2호·제3호 목 번호 재확인.
- 지자체별 이행강제금 위반면적 산정 관행(바닥면적 vs 연면적) 샘플 3개 구 확인.
