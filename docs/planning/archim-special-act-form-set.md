# 아키엠 특정건축물 양성화 — 서식·산출물 세트 점검 v0.1

작성일: 2026-10-18 · 상위 문서: `archim-special-act-field-survey-plan.md`(v0.4)
목적: 현장조사서 외에 신고 패키지 안에서 **아키엠이 만들 수 있는 서식·산출물**을 전수 점검하고, 생성 가능 수준과 우선순위를 정한다.

> 법정 서식(별지)은 2026 시행령 제정안(입법예고 2026.9.30~11.9) 첨부로 확정된다. 아래 "법정" 구분은 2014년 제도와 2026년 지자체·실무 안내에서 공통으로 요구된 항목을 기준으로 한 **후보**이며, 별지 확보 후 명칭·항목을 재정렬한다.

## 0. 결론 요약

| 구분 | 건수 | 아키엠 역할 |
|---|---|---|
| A. 법정 서식(건축사·신고인 작성) | 3 | **생성** — 신고서·현장조사서·설계도서(현황도) |
| B. 공부 사본(발급 문서) | 6 | **수집·OCR·첨부** — 생성 대상 아님, 자동 조회·판독·패키징 |
| C. 사실 입증 자료 | 6~8 | **수집·정리·목록화** — 완공시점·소유권·동의 |
| D. 앱 고유 산출물(법정 아님, 실무 필수) | 9 | **생성** — 위반현황표·사진대지·과태료 추정·심의 대응 등 |
| E. 사무소 운영 문서 | 5 | **생성(템플릿)** — 견적·계약·안내·완료보고 |
| J. 템플릿 라이브러리 | — | **저장·다운로드** — 법정 원본·아키엠 표준·사무소 커스텀 빈 서식 배포, 버전 관리 |

현장조사서 하나를 만들기 위해 모이는 데이터(대장·실측·사진·체크·산정)로 **A 3종 + D 9종 + E 5종 = 17종**을 추가 입력 없이 뽑아낼 수 있다. 이것이 "현장 1회 방문으로 신고 패키지 완성"의 실체다.

## A. 법정 서식 — 앱이 생성

| # | 서식 | 작성 주체 | 아키엠 생성 수준 | 데이터 소스 | 화면 | 우선 |

| A-1 | **특정건축물 신고서**(별지) | 신고인(건축주·소유자) | **완전 생성**. 신고인·대지·건축물 개요·첨부 목록 자동 채움, 신고인 서명란만 비움 | Applicant + Site + BuildingRecord | PC 22 문서 드롭다운 | MVP |
| A-2 | **현장조사서**(별지) | 건축사 | **초안 생성 → 건축사 확정·서명** (상위 문서 §5.5·§6) | Survey·Violation·Calculation | 11 AI 초안 → PC 20 | MVP |
| A-3 | **설계도서**(현황 배치도·각층 평면도·단면도·입면도, 면적 산출표) | 건축사 | **부분**: 면적 산출표·층별 개요표는 생성, 도면은 **실측 데이터 export(DXF/CSV)+현황 스케치 첨부**까지. 도면 작도는 건축사 CAD | Measurement·Violation·Photo(스케치) | 26 도면 관리 + 신규 export | MVP(표) / v1.2(스케치 자동화) |

## J. 템플릿 라이브러리 — 저장·다운로드(2026-10-18 대표 지시)

사용자는 데이터를 채우지 않아도 **서식 자체를 내려받아 쓸 수 있어야 한다.** 앱이 자동 생성한 문서와 별개로, 빈 서식·사무소 커스텀 서식을 저장·배포하는 템플릿 라이브러리를 둔다.

| 종류 | 내용 | 형식 | 편집 가능 |

| 공유 | 템플릿을 다른 사무소에 공개(선택). 법정 원본은 출처 링크 포함 | v1.2 |

### J-3. 치환 태그 규칙(초안)

- 형식 `{{entity.field}}` 예: `{{applicant.name}}`, `{{building.gross_area_m2}}`, `{{violations[].area_violation}}`(반복 행)
- 서명·날짜 칸은 `{{sign.architect}}`, `{{date.survey}}`처럼 **비워 두는 태그**로 표시. 자동 생성 시 서명 칸은 절대 채우지 않는다(상위 문서 §10 작성 주체 원칙)
- 태그 사전은 데이터 모델(상위 문서 §7)에서 자동 생성, 서식 편집 화면에 삽입 목록으로 제공

### J-4. 저장 구조

```
templates/
  legal/            # 법정 원본 — 읽기 전용, version, source_url, effective_from
    special_act_decree_2026_draft/   # 입법예고본
    special_act_decree_2026_final/   # 공포본(확보 후)
    jurisdiction/<sigungu_code>/     # 지자체 첨부 서식
  standard/         # 아키엠 표준 — 치환 태그 포함, version
  office/<office_id>/   # 사무소 커스텀 — version, editor, base_template_id
```

### J-5. 우선순위

- MVP: 법정 원본·아키엠 표준의 **빈 서식 다운로드**, 채운 서식 다운로드(기존), 기본 템플릿 지정, 버전 기록
- v1.1: 사무소 커스텀 저장·편집, 태그 유효성 검사, 패키지 묶음 다운로드
- v1.2: 템플릿 공유, 지자체 커스텀 관리자 화면

### J-6. 리스크

- 법정 원본 hwp 재배포 시 출처(법제처·지자체) 표기 유지. 원본 변형본을 "법정 서식"으로 표시하지 않는다.
- 사무소 템플릿이 법정 항목을 삭제하면 접수 반려 위험 → 아키엠 표준 대비 **필수 항목 누락 검사**를 저장 시 수행.
