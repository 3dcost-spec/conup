## 0. 한 장 요약

| 구분 | 내용 |
|---|---|
| 무엇을 | 건축사가 양성화 신고에 첨부해야 하는 **현장조사서**(법 제4조)와 그 증빙(사진대지·위반현황표·현황스케치)을 아키엠에서 **현장 1회 방문으로 완성** |
| 어떻게 | 아키엠의 기존 파이프라인 **현장 등록 → 날짜·공종 선택 → 사진·마크업 → 공종별 체크리스트 → AI 생성형 일지 → 미리보기·공유 → PC 법정서식 출력**을 그대로 쓰되, 조사 대상을 "공사 중 건축물"에서 "기존 위반 건축물"로 바꾼 **네 번째 감리 유형 「특정건축물 조사」**를 추가 |
| 왜 아키엠 | 공종별 체크리스트 = 조사 분야 체크리스트, AI 감리일지 = AI 현장조사서 초안, 사진대지 = 조사 사진대지, PC 문서(사용승인조사서·검사조서) = 현장조사서 hwp/pdf, 서명 = 건축사 서명. **새 모듈이 아니라 템플릿·서식·판정 로직의 추가** |
| 시장 | 전국 동시 발생·18개월 한시·동일 서식 반복 → 템플릿형 SaaS 적합. 2014년 특조법 때 신고 수만 건(국토부 통계 재확인 필요) |
| 출시 목표 | **2026.12.17 시행 전 MVP**(약 8주), 2027 Q1 v1.1 |
| 원칙 | AI는 제안, 확정·서명·적합 판정은 **건축사**. 앱은 "작성 보조 도구"임을 UI·약관에 명시 |

| 용도 | 대장 용도 + 현장 용도 | 주거 ≥ 50% 연면적 | 충족 / 미달 |
| 면적 | 대장 + 위반 포함 실측 | 유형별 상한(단독165/조례330, 다가구660*, 다세대 세대당85) | 충족 / 조례 확인 / 초과 |
| 구역 | 토지이용계획 | 제외구역 키워드 매칭 | 해당없음 / 해당(사유) |
| 이력 | 대장 변동사항 | 과거 특조법 승인 + 소유권 변동 없음 → 제외 | 해당없음 / 제외 |

- 면적 상한·주거비율·과태료 산식은 **LawParams 버전 테이블**(코드 분리). 시행령 공포 시 관리자 화면에서 갱신.
- 지자체 조례 상한·서식·접수처는 **JurisdictionParams(시군구 코드)**.
- 판정 결과에 근거 조문·자료를 함께 저장 → 심의 보완 대응 시 재사용.

### 5.2 공부 연동(04 AI 등록 확장)

- 1차(MVP): 건축물대장·토지이용계획확인원·지적도 **촬영/PDF 업로드 → OCR → 대장 현황 카드**. 아키엠 "AI 분석은 100% 정확하지 않음, 검토 후 저장" 원칙 유지.
- 2차(v1.1): 건축HUB(대장 표제부·전유부·층별개요)·토지이음 API. 실패 시 OCR 폴백.

### 5.3 현장 조사 모듈(06·07·10·15 재사용)

**조사 분야 체크리스트(= 공종 축 치환)**

| 분야 | 주요 항목 |
|---|---|
| 대지 | 경계·건축선 침범, 접도 폭, 대지안의 공지, 조경, 주차 대수·전용 |
| 외관·규모 | 층수·높이, 옥탑, 외부계단, 발코니·베란다 확장, 캐노피·창고 증축 |
| 층별 내부 | 용도(주거/근생/창고), 세대 분할, 다락 거실화, 필로티 전용, 지하 거실화 |
| 구조 | 증축부 구조형식(경량철골/RC/목조), 접합 상태, 균열·처짐·누수·부식, 기초 |
| 피난·방화 | 직통계단 거리, 방화구획·방화문, 내화, 복도·출입문 폭, 피난 경로 |
| 설비 | 전기(분전반), 가스, 급배수, 소방(감지기·소화기), 환기 |
| 일조·인접 | 정북 이격, 인접 경계 이격, 차면 |

**AI 기능**
- 15 AI 사진 분석에 **「위반건축물」** 분류 추가: 위반유형 Top-3 + 신뢰도 + 근거(사진 영역). 제안 상태로 저장, 조사자 확정 전 서식 반영 금지.
- 사진 ↔ 동·층·분야 자동 매핑(촬영 전 선택 정보 자동 입력 — 07 원칙).
- **음성 소견**: 막찍는 현장조사앱의 온디바이스 전사(보이스태그 모듈) 재사용. 반지하·옥탑 통신 불량 대비 오프라인 전사.
- 누락 감지: 분야별 필수 사진·항목 미입력 시 조사서 생성 soft block.
- 실측: 마크업 줄자 + 수치 입력(MVP) → 레이저 거리계 BT·LiDAR 평면 스캔(v1.2).

### 5.4 위반현황 산정(신규 화면)

- 층별 표: 대장 면적 / 실측 면적 / 차이(위반) / 용도 / 구조 / 위반유형 코드.
- 재계산: 건축면적·연면적·건폐율·용적률·높이·세대수 + 법정 한도 대비 초과 플래그.
- 위반유형 코드: 무허가 신축 / 무단 증축 / 무단 대수선 / 용도변경 / 세대 분할 / 대지 위반.
- 심의 쟁점 자동 표시: 한도 초과 폭, 피난·방화 미충족, 구조 확인 필요.

### 5.5 AI 현장조사서 초안(11 AI 일지 변형)

- 입력: 대장 현황 카드 + 사진(확정 라벨) + 체크리스트 + 실측 + 음성 소견.
- 출력 스키마: ① 건축물 개요 ② 위반 현황(층별) ③ 조사 내용(법규 적합성) ④ 구조안전 ⑤ 피난·방화·설비 ⑥ 종합 의견 초안 ⑦ 보완 필요사항.
- 원칙(음성 혁신안 승계): 「AI 초안 · 확인 전」 배지, 입력에 없는 수치·판정은 "미기재/확인 필요", 각 문장은 사진·체크 카드로 역추적.

### 5.6 PC 서식·출력(20·21·22·23)

- 문서 드롭다운 추가: **특정건축물 현장조사서 / 위반현황표 / 과태료 추정서 / 신고 체크리스트**.

### 5.8 과태료 시뮬레이션

## 9. 아키텍처·기술 메모

- **클라이언트**: 아키엠 모바일(현장) + PC 웹(서식·서명). 오프라인 촬영·전사 후 동기화(반지하·옥탑 통신 불량).
- **AI**: 위반유형 분류는 MVP에서 멀티모달 LLM 프롬프트(기존 공사/하자/안전 분석과 동일 경로) → 데이터 축적 후 파인튜닝 검토. 대장 OCR은 04 AI 등록의 도면 분석 경로 재사용. 조사서 초안은 11 생성형 일지 경로에 출력 스키마만 교체. 모든 AI 출력은 제안 상태 + 확정 로그.
- **음성**: 막찍는 현장조사앱의 온디바이스 전사·보이스태그 모듈 공통 호출(기록유형 "조사 소견" 추가).
- **서식 엔진**: PC 21의 한글 출력 경로 재사용. 템플릿 버전·시군구별 다중 지원.
- **공공데이터**: 건축HUB·토지이음 API 키 발급(v1.1). 실패 시 OCR 폴백 필수.
- **법령 파라미터**: LawParams/JurisdictionParams 관리자 화면.
- **보안·개인정보**: 소유자 정보·공부 사본 암호화, 건축주 열람 범위 제한, 보존기간(제도 종료 후 n년) 설정.
- **토큰**: 선제 제안(조사서 초안 생성)의 AI 토큰 소모 상한 설계(혁신안 A-10 승계).

## 부록 A. LLM 프롬프트·출력 스키마 초안(D-2)

세 호출 모두 기존 아키엠 AI 경로(04 도면 분석 · 11 생성형 일지 · 15 사진 분석)의 입력 자리에 프롬프트와 JSON 스키마만 바꿔 끼운다. 출력은 전부 **제안**이며 `confirmed=false`로 저장된다.

### A-1. 위반유형 분류(15장 「위반건축물」 분석)

입력: 사진 1~N장 + 문맥(동·층·조사 분야·대장 용도·구조) + ViolationType 코드표.

```
역할: 한국 건축법 위반건축물 현장조사를 보조하는 분석기. 판정하지 말고 후보를 제안한다.
문맥: {동}/{층}/{분야}, 대장상 용도 {use}, 구조 {structure}, 층수 {floors}
코드표: V01 무허가 신축 / V02 무단 증축(옥탑) / V03 무단 증축(발코니·베란다 확장) / V04 무단 증축(외부계단·캐노피·창고)
       / V05 무단 대수선 / V06 용도변경(근생→주거) / V07 세대 분할 / V08 필로티·주차장 전용 / V09 다락·지하 거실화
       / V10 대지 위반(건축선·공지·조경) / V00 위반 징후 없음
지시: 사진에서 관찰되는 사실만 근거로 코드 후보 최대 3개를 신뢰도와 함께 제안. 추정 구조형식(경량철골/RC/목조/판넬)과
     사진에서 보이는 치수 단서(창호 수·블록 단수 등)를 적되, 면적·적법 여부는 쓰지 않는다. 불확실하면 V00과 함께 "추가 촬영 필요"를 적는다.
```

```json
{
  "candidates": [{"code": "V02", "confidence": 0.82, "evidence": "옥상 슬래브 위 경량철골 프레임과 판넬 외벽, 대장 층수 3층 대비 4층 상부 구조물"}],
  "structure_guess": "경량철골+샌드위치판넬",
  "size_clues": ["창호 3개소", "판넬 폭 기준 약 4~5m 추정"],
  "needs_more_photos": ["옥탑 내부", "접합부 근접"],
  "disclaimer": "법적 양식 아님 · 참고 의견"
}
```
