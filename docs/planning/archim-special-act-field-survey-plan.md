# 아키엠(ArchiM) — 특정건축물 양성화 현장조사서 기능 기획안 (v0.1)

작성일: 2026-10-18
상태: 초안 (시행령·시행규칙 공포 전, 서식 확정 전)
대상 앱: 아키엠 (AI 감리 앱)
관련 법령: 「특정건축물 정리에 관한 특별조치법」(법률 제21820호, 2026.6.16. 공포, 2026.12.17. 시행, 18개월 한시 → 2028.6.16. 종료)

---

## 0. 한 줄 요약

건축사가 양성화 신고에 첨부해야 하는 **현장조사서**(법 제4조, 건축사 작성 의무)를
아키엠의 기존 감리 역량(사진·체크리스트·AI 판독·보고서 생성)으로 **현장에서 1회 방문으로 완성**하게 한다.
핵심 가치는 ①대상 적격성 사전 판정, ②위반현황 실측·사진 증빙의 구조화, ③법정 서식 자동 출력, ④건축위원회 심의 보완 최소화.

## 1. 배경과 기회

### 1.1 제도 요지 (확인된 범위)

| 항목 | 내용 | 확인 수준 |
|---|---|---|
| 시행·종료 | 2026.12.17. 시행, 18개월 한시(2028.6.16.) | 법률 공포 사실 확인 |
| 대상 완공시점 | 2023.12.31. 당시 사실상 완공된 주거용 특정건축물 | 민간 해설 다수 일치, 원문 재확인 필요 |
| 면적 기준 | 단독 연면적 165㎡ 이하(165~330㎡는 조례), 다가구 660㎡ 이하, 다세대 세대당 전용 85㎡ 이하 | 해설마다 다가구 수치 상이(330/660) → 시행령 확정 후 반영 |
| 주거용 요건 | 연면적 50% 이상 주거용 | 민간 해설 |
| 제외 구역 | 도시·군계획시설 부지, 개발제한구역, 군사기지·시설보호구역, 접도구역, 도시개발구역, 정비구역, 보전산지, 상습재해·환경정비구역(대통령령) | 법률 부칙·해설 |
| 제외 건축물 | 과거(2000·2006·2014) 특조법으로 사용승인 받고 소유권 변동 없는 건축물 | 법률 해설 |
| 신고 서류 | **건축사가 작성한 설계도서 + 현장조사서**, 대지 소유·사용권 증명 등 | 법 제4조 |
| 절차 | 신고 → 지자체 건축위원회 심의 → 적합 시 30일 내 사용승인서 교부 | 법률·해설 |
| 비용 | 이행강제금 5회분 상당 과태료(기납부 이행강제금 차감) | 민간 해설, 원문 확인 필요 |
| 지원센터 | 지자체 특정건축물 지원센터 설치 가능(법 제5조) | 법률 확인 |

> 강북구 공고(gangbuk.go.kr nttId=184501)는 본 작업 환경에서 접근이 차단되어 본문을 확인하지 못했다.
> 구 단위 공고에는 보통 **접수기간·접수처·구 조례상 단독주택 면적 상한(165 vs 330)·현장조사서 서식 첨부**가 실리므로, 첨부 서식(hwp)을 확보해 §5 서식 매핑에 반영해야 한다.

### 1.2 왜 아키엠인가

- 2014년 특조법 당시 현장조사는 건축·구조·설비 전 분야를 건축사 1인이 수행했고, 사진·실측·서식 작성이 전부 수작업이었다. 학계도 전문기술자 참여 부족을 지적했다.
- 아키엠은 이미 **현장 사진 → AI 판독 → 체크리스트 → 보고서**의 감리 파이프라인을 갖고 있다. 현장조사서는 이 파이프라인의 "대상 객체"를 공사 중 건축물에서 **기존 위반 건축물**로 바꾼 변형이다.
- 18개월 한시 제도이므로 **수요가 짧고 집중**된다. 전국 건축사사무소가 동시에 같은 서식을 반복 작성한다 → 템플릿형 SaaS 적합.
- 2014년 기준 신고 건수는 수만 건 규모였다(정확 수치는 국토부 자료 재확인). 1건당 건축사 보수 수십만~수백만 원 시장.

### 1.3 타깃 사용자

| 역할 | 니즈 | 앱 내 권한 |
|---|---|---|
| 건축사(작성자) | 법적 책임 하에 현장조사서·설계도서 작성, 심의 통과 | 프로젝트 소유, 최종 서명 |
| 조사 보조원(사무소 직원) | 현장 사진·실측·체크리스트 입력 | 입력·편집, 서명 불가 |
| 건축주·소유자 | 대상 여부 사전 확인, 서류 제출, 진행 상황 확인 | 조회, 자료 업로드 |
| 행정사·대행업체 | 다건 접수 관리, 과태료 안내 | 프로젝트 관리(옵션) |

## 2. 제품 범위

### 2.1 포함 (In scope)

1. **적격성 사전판정 위저드** — 완공시점·용도·면적·구역·이력 5개 축 자동 판정
2. **공부(公簿) 연동** — 건축물대장·토지이용계획·지적 자료 불러오기, 대장 vs 현황 차이 자동 추출
3. **현장조사 모듈** — 사진(AI 위반유형 태깅), 실측(치수·면적), 음성메모, 분야별 체크리스트
4. **위반현황 산정** — 층별·용도별 위반 면적 표, 건폐율·용적률 재계산
5. **현장조사서 생성** — 법정 서식(hwp/pdf) + 사진대지 + 현황 스케치 자동 조판
6. **구조안전 확인 체크** — 육안조사 체크리스트 + 구조기술사 확인 필요 여부 플래그
7. **과태료(이행강제금 5회분) 시뮬레이션** — 시가표준액·위반면적 기반 추정
8. **신고 패키지 export 및 진행 관리** — 접수·보완·심의·사용승인 단계 추적

### 2.2 제외 (Out of scope, v1)

- 설계도서(현황도면) CAD 제작 자체 — 건축사 CAD 영역. 앱은 실측 데이터·스케치를 DXF/CSV로 export만 함
- 구조안전 계산 — 구조기술사 영역. 앱은 "확인 필요" 판정과 자료 정리까지
- 지자체 전자접수 연동 — 세움터 API 개방 여부 미확인, v2 검토
- 비주거(근생·공장) 위반건축물 — 이번 특조법 대상 아님

## 3. 사용자 여정 (건축사 기준)

```
[의뢰 접수] → [사전판정] → [공부 연동] → [현장조사] → [위반 산정] → [서식 생성] → [검토·서명] → [신고·추적]
   건축주         5축 자동       대장/지적       사진·실측     면적표·율    hwp/pdf      건축사 서명     단계 알림
   정보 입력      판정+근거      diff 추출      체크리스트    재계산       사진대지     법적책임 고지   보완 대응
```

1. **의뢰 접수**: 건축주가 링크로 주소·연락처·완공시점 증빙(항공사진, 재산세 고지서, 공과금 영수증 등) 업로드
2. **사전판정**: 앱이 "대상 가능 / 조례 확인 필요 / 대상 불가(사유)" 3단계 판정. 불가 사유 예: 정비구역 포함, 2024년 이후 증축, 주거비율 미달
3. **공부 연동**: 건축물대장(표제부·전유부), 토지이용계획확인원, 지적도 자동 조회 → 대장상 면적·층수·용도 세팅
4. **현장조사**: 분야별 탭(대지·외관·층별 내부·구조·피난방화·설비) 순서로 사진 촬영. AI가 사진에서 위반 유형 후보 제시(옥탑 무단증축, 발코니 확장, 필로티 주차장 전용, 다락 거실화, 외부계단, 근생→주거 전용, 세대 분할 등). 조사자가 확정
5. **위반 산정**: 층별 실측값 입력 → 대장 면적과 차이 = 위반 면적. 건폐율·용적률·높이 재계산, 법정 한도 초과 여부 표시
6. **서식 생성**: 현장조사서 본문 + 사진대지 + 층별 현황 스케치 + 위반 면적표 → hwp/pdf
7. **검토·서명**: 건축사 검토 화면에서 AI 제안 항목 전수 확인 후 전자서명. "본 조사서의 법적 책임은 작성 건축사에게 있음" 고지 필수
8. **신고·추적**: 접수번호 등록 → 보완요구·심의일·결과 단계 관리, 18개월 종료일 카운트다운

## 4. 기능 상세

### 4.1 적격성 사전판정 엔진

| 판정 축 | 입력 | 판정 로직 | 출력 |
|---|---|---|---|
| 완공시점 | 항공사진 연도, 과세 이력, 사용자 진술 | 2023.12.31. 이전 사실상 완공 증빙 1건 이상 | 충족 / 증빙 부족 |
| 용도 | 대장 용도 + 현장 용도 | 주거용 ≥ 50% 연면적 | 충족 / 미달 |
| 면적 | 대장 + 위반 포함 실측 | 유형별 상한(단독165/조례330, 다가구660*, 다세대 세대당85) | 충족 / 조례확인 / 초과 |
| 구역 | 토지이용계획 | 제외구역 키워드 매칭(정비구역, GB, 군사보호, 접도, 도시개발, 보전산지, 도시계획시설) | 해당없음 / 해당(사유) |
| 이력 | 대장 변동사항 | 과거 특조법 사용승인 + 소유권 변동 없음 → 제외 | 해당없음 / 제외 |

- 면적 상한·주거비율은 **설정 테이블(법령 파라미터)**로 분리하여 시행령 공포 시 코드 수정 없이 갱신
- 지자체별 조례 상한(165~330)은 **시군구 코드별 테이블**로 관리, 공고 수집 시 업데이트
- 판정 결과에는 **근거 조문·자료 출처**를 함께 표시(심의 보완 대응 시 재사용)

### 4.2 공부 연동

- 건축HUB(건축물대장 표제부·전유부·층별개요) 공공데이터 API
- 토지이음(토지이용계획) API 또는 PDF 업로드 후 OCR
- 지적도 WMS 또는 이미지 업로드
- 산출: "대장 현황 카드" (층별 용도·면적·구조·세대수) → 현장조사 기준값으로 자동 배치
- API 장애·미개방 대비: **PDF/이미지 업로드 + OCR 폴백** 필수

### 4.3 현장조사 모듈 (아키엠 핵심 재사용)

**체크리스트 (분야별)**

| 분야 | 주요 항목 |
|---|---|
| 대지 | 경계·건축선 침범, 도로 접도 폭, 대지안의 공지, 조경, 주차 대수·전용 여부 |
| 외관·규모 | 층수, 높이, 옥탑, 외부계단, 발코니·베란다 확장, 캐노피·창고 증축 |
| 층별 내부 | 용도(주거/근생/창고), 세대 분할(방쪼개기), 다락 거실화, 필로티 전용, 지하 거실화 |
| 구조 | 증축부 구조형식(경량철골/RC/목조), 기존 구조와 접합 상태, 균열·처짐·누수·부식, 기초 유무 |
| 피난·방화 | 피난계단·직통계단 거리, 방화구획·방화문, 내화구조, 복도·출입문 폭, 비상 피난 경로 |
| 설비 | 전기(차단기·분전반), 가스, 급배수, 소방시설(감지기·소화기), 환기 |
| 일조·인접 | 정북방향 이격, 인접 대지 경계 이격, 창문 차면 |

**AI 기능**

- 사진 분류: 위반유형 라벨 후보 Top-3 + 신뢰도. 조사자 확정 전까지 "제안" 상태
- 사진 ↔ 층·위치 자동 매핑(촬영 순서·GPS·조사자 지정)
- 음성 메모 → 조사 소견 문장 초안 변환
- 누락 감지: 분야별 필수 사진·항목 미입력 시 서식 생성 차단(soft block) 및 경고
- 실측 보조: 레이저 거리계 Bluetooth 연동(옵션), LiDAR 기기 평면 스캔(iOS, v1.1)

### 4.4 위반현황 산정

- 층별 표: 대장 면적 / 실측 면적 / 차이(위반) / 용도 / 구조
- 재계산: 건축면적·연면적·건폐율·용적률·높이·세대수
- 위반 유형 코드화(무허가 신축, 무단 증축, 무단 대수선, 용도변경, 세대 분할, 대지 위반)
- 심의 쟁점 자동 표시: 법정 한도 초과 폭, 피난·방화 미충족 항목, 구조 확인 필요 항목

### 4.5 현장조사서 생성

- 2014년 시행규칙 별지 현장조사서 구성을 기준 템플릿으로 하고, 2026년 시행규칙 서식 공포 시 교체 (서식 매핑은 §5)
- 출력: hwp(한컴 호환 필수, 지자체 접수용), pdf, docx
- 첨부 자동 조판: 사진대지(사진번호·위치·내용·일시), 층별 현황 스케치(위반부 해칭), 위반면적표, 공부 사본
- 지자체별 공고 첨부 서식이 다를 경우 **템플릿 다중 지원**(시군구 코드별)

### 4.6 구조안전 확인 보조

- 육안조사 체크 결과를 점수화하여 "구조기술사 확인 권고" 플래그
- 증축부 구조형식·규모별로 구조안전확인서 요구 가능성 안내(지자체 심의 관행 반영)
- 구조기술사 의뢰용 자료 패키지(사진·실측·스케치) export

### 4.7 과태료 시뮬레이션

- 입력: 위반면적, 시가표준액(㎡당), 위반 유형, 기납부 이행강제금
- 산식: 이행강제금 1회분 × 5 − 기납부액 (시행령 확정 시 산식 테이블 갱신)
- 결과는 "추정치, 지자체 부과액과 다를 수 있음" 고지 필수

### 4.8 진행 관리

- 단계: 의뢰 → 조사 → 서식 완료 → 접수 → 보완 → 심의 → 사용승인/반려
- 알림: 접수 마감(2028.6.16.), 보완 기한, 심의일
- 사무소 대시보드: 건별 단계·담당자·수익

## 7. 기술 아키텍처 메모

- **클라이언트**: 아키엠 기존 모바일 앱(현장) + 웹(사무소 검토·서식 생성). 오프라인 촬영·입력 후 동기화 필수(반지하·옥탑 통신 불량)
- **AI**: 사진 위반유형 분류 모델(기존 감리 결함 분류 모델 파인튜닝 또는 멀티모달 LLM 프롬프트 기반으로 MVP), 음성→텍스트, 종합의견 초안 LLM 생성. 모든 AI 출력은 "제안" 상태로 저장, 확정 로그 별도
- **서식 엔진**: hwp 생성(hwpx 템플릿 치환 또는 docx→hwp 변환 서버), pdf 조판
- **공공데이터**: 건축HUB·토지이음 API 키 발급, 호출 실패 시 OCR 폴백
- **법령 파라미터**: 코드와 분리된 버전 테이블, 시행령·조례 변경 시 관리자 화면에서 갱신
- **보안·개인정보**: 소유자 개인정보·공부 사본 암호화 저장, 건축주 열람 범위 제한, 보존기간 설정(제도 종료 후 n년)

## 8. 법적·운영 리스크

| 리스크 | 내용 | 대응 |
|---|---|---|
| 작성 주체 | 현장조사서는 **건축사** 작성 의무. 앱이 "작성"하는 것으로 비치면 건축사법 저촉 소지 | 앱은 "작성 보조 도구", 최종 확정·서명은 건축사만 가능. UI와 약관에 명시 |
| AI 오판 | 위반 유형·면적 AI 제안 오류 → 심의 반려·건축사 책임 | 모든 AI 출력 제안 상태, 확정 로그, 신뢰도 표시, 필수 항목 사람 확인 |
| 서식 불일치 | 시행규칙·지자체 서식 미확정 | 템플릿 다중·버전 관리, 공포 즉시 교체 체계 |
| 법령 파라미터 변경 | 면적 기준(다가구 330/660 혼선) 등 | 파라미터 테이블화, 출처·버전 표시 |
| 과태료 안내 | 추정치가 실제와 다를 때 분쟁 | 추정치 고지, 산식·입력값 공개 |
| 완공시점 증빙 | 허위 증빙 유도 우려 | 앱은 증빙 "수집·정리"만, 판단은 건축사·지자체 |
| 한시 제도 | 18개월 후 수요 소멸 | 코어(현장조사·서식 엔진)를 일반 위반건축물 실태조사·이행강제금 대응·감리에 재사용 가능하게 설계 |

## 10. 성공 지표 (MVP)

- 현장 1회 방문으로 조사서 초안 완성률 ≥ 80%
- 현장 체류 시간 기존 대비 40% 단축(건축사 인터뷰 베이스라인 대비)
- 심의 보완 요구 건수 비율 베이스라인 대비 30% 감소
- 서식 생성 후 건축사 수정 항목 수 ≤ 5개/건
- 시행 후 3개월 내 활성 건축사사무소 n개, 조사서 n건 (목표치는 P0 인터뷰 후 설정)

## 11. 열린 질문 (의사결정 필요)

1. 아키엠 기존 감리 프로젝트 구조와 **동일 Project 엔티티**로 둘지, 별도 "양성화" 프로젝트 타입으로 분리할지
2. hwp 생성 방식: hwpx 템플릿 치환(자체) vs 외부 변환 서비스 — 지자체 접수는 hwp가 사실상 표준
3. AI 위반유형 분류를 기존 결함 모델 파인튜닝으로 갈지, 멀티모달 LLM 프롬프트로 MVP 먼저 갈지
4. 건축주 셀프 사전판정(B2C 리드 생성)을 공개 웹으로 열지, 건축사 초대 링크로만 열지
5. 설계도서(현황도면) 영역을 어디까지 끌어올지 — 실측 export까지만 vs 평면 자동 생성
6. 과금: 건당 과금 vs 사무소 구독 vs 아키엠 기존 플랜 포함
